# terminal-site

The shunpo landing page - a React + TypeScript + Tailwind CSS app built with Vite, styled to look and feel like an actual terminal (draggable tabs, recursive pane splitting, resizable dividers).

## Develop

```
pnpm install
pnpm dev
```

## Build

```
pnpm build
```

Outputs a static `dist/` ready to deploy anywhere (GitHub Pages, Vercel, Netlify, etc.) - no server required.
